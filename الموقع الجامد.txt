1) التحويل لـ SPA فانيليا (بدون React، بدون CDN، بدون build عند التشغيل)
-----------------------------------------------------------
- تم إبقاء الموقع HTML/CSS/JS خالصاً ("GG اللي في React") وإضافة المكتبات
  المطلوبة لكن مدمجة (bundled) في ملف واحد: vendor/vendor.bundle.js
- الموقع يعمل بمجرد فتح index.html أو رفعه لأي استضافة ثابتة بدون أي CDN.

المكتبات المدمجة:
  - GSAP ......... حركات دخول الصفحات (كروت، أشرطة التقدم، الحلقات)
  - Lenis ......... تمرير سلس (متوافق مع prefers-reduced-motion)
  - canvas-confetti .... كرات نجاح (وسام/إنجاز/توقّع CTR عالي)
  - @formkit/auto-animate .. انتقالات ناعمة في القوائم/الجدران
  - lucide ....... الأيقونات (مع بديل مرسوم إذا غابت أيقونة)
  - zustand ...... مخزن حالة خفيف (Ux)
  - clsx + tailwind-merge .. وظيفة لدمج الفئات (cn)
  - طبقة جلب بذاكرة (data-layer) بديلة عن React Query

تجديد الحزمة:  npm install ثم npm run vendor
فحص سريع:      npm run check  |  npm run smoke

-----------------------------------------------------------
3) جاهزية الربط مع Google AdSense وبوابات التبرع
-----------------------------------------------------------
كل الإعدادات في js/data.js ضمن CONFIG — بدون أي روابط ميتة:

أ) رابط مستودع GitHub (لتفعيل زر GitHub + "View the source" + المساهمة):
      CONFIG.repoUrl = "https://github.com/اسمك/viralforge"

ب) بوابات التبرع (تفعّل أزرار الصفحة تلقائياً):
      CONFIG.buymeacoffee = "https://www.buymeacoffee.com/اسمك"
      CONFIG.patreon      = "https://www.patreon.com/اسمك"

ج) إعلانات Google AdSense (البطاقتان تعملان فور الإدخال):
      CONFIG.adsense.client = "ca-pub-XXXXXXXXXXXXXXX"
      CONFIG.adsense.slots  = { sidebar: "معرف_الوحدة", footer: "معرف_الوحدة" }

د) بديل: بطاقة راعي (سبونسر) بدل AdSense:
      CONFIG.adsense.custom = "https://رابط/إعلانك"

أنظر: طريقة الحقن في js/ads.js (يحقن وحدات <ins> ويحمّل سكربت AdSense بنفسه).


-----------------------------------------------------------
4) التشغيل
-----------------------------------------------------------
في مجلد viralforge:
  npm install      (مرة واحدة لأدوات التطوير)
  npm run serve    (سيرفر على http://localhost:3000)
أو افتح index.html مباشرة بالنقر المزدوج (تغيّر ملاحظة: البحث الرائج يحتاج سيرفر).

رفع مجاني: GitHub Pages / Netlify / Vercel / Cloudflare Pages — مجلد واحد بلا إعدادات.
